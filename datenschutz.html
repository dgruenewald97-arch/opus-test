Datenschutz

Diese Hinweise beschreiben die technische Datenverarbeitung der veröffentlichten GRELLWERK-Demo.

Projekt und Hosting

GRELLWERK ist ein Gestaltungskonzept im Repository dgruenewald97-arch/opus-test. Die öffentliche Website wird über GitHub Pages ausgeliefert. Laut GitHub-Dokumentation protokolliert und speichert GitHub dabei IP-Adressen von Besuchern zu Sicherheitszwecken. Weitere Angaben stehen in GitHubs Datenschutzerklärung.

Briefing und interaktive Werkzeuge

Kontaktformular, Konfigurator und Slogan-Werkzeug laufen lokal im Browser. Die Website sendet ihre Eingaben nicht an einen Server. Wenn du einen Kopierknopf betätigst, schreibt die Website den angezeigten Text mit deiner Browserfreigabe in die Zwischenablage. Eine spätere Weitergabe dieses Textes entscheidest du selbst.

Bewegungseinstellung

Der Pausenschalter speichert deine Auswahl unter grellwerk-still im sessionStorage für die aktuelle Browsersitzung. Es werden dabei keine Formularangaben gespeichert. Die Einstellung kann durch Löschen der Browserdaten entfernt werden.

Medien, Schriften und Messung

Die aktive Website lädt ihre Schriften, Bilder, GIFs, Videos und Skripte vom gleichen Hosting. Sie bindet keine Google-Fonts- oder Analyse-Skripte ein und setzt selbst keine Tracking-Cookies. Die Stockaufnahmen werden als lokale Dateien ausgeliefert; beim Abspielen entsteht keine Verbindung zu Mixkit.

Fragen und Rechte

Die Bezeichnung als Demo hebt Datenschutzrechte nicht auf. Hinweise zur Verarbeitung durch GitHub und Kontaktmöglichkeiten zu GitHub findest du in der oben verlinkten Datenschutzerklärung. Technische Fragen zur Website können über das Projekt-Repository gestellt werden.
