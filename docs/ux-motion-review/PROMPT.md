# PROMPT · Creative Direction

Befunde: `work-view.cjs` verspricht vier eigene Welten; die Leitzeilen tragen diese Trennung. `site.cjs` setzt KOLD jedoch auf Lime statt Gelb und nähert es NEON an. `showcase.cjs` bietet Markenmotiv und Detail, aber noch keine durchgängige Alltagsszene pro Produkt.

Vier ergänzende Fotos sind freigegeben, verbindlich:

- KOLD: bestehende schwarze Dose/gelbe Krone, Hand am Nachtkiosk; gelb/schwarz. Bewegung: kurzer Lichtwechsel, kein Lime.
- NEON: identischer schwarz/weiß/lime Schuh im echten Schritt auf nassem Asphalt. Bewegung folgt dem Schritt, keine Lichtspuren.
- HAFER: identische Packung in neutraler Morgenküche; natürliches Licht. Bewegung: ruhiger Handgriff, kein Nachtlook.
- BLITZ: unveränderte schwarze Karte in einer Hand vor ruhigem strukturiertem Beton. Bewegung: klare Kartenwendung, keine verzerrten Zeichen.

Filmhero/GIFs bleiben; Pause und reduzierte Bewegung erhalten. Stock ausschließlich Atmosphäre. Keine Collage, eingebrannten Headlines, Institutionen oder behaupteten Ergebnisse. VISUAL hält Produktidentität, VOICE die Leitidee konsistent.
